# Deneme Sınavı — Puanlama Anahtarı (Matematik)

Toplam 100 puan. Değerlendirme: 85+ hazır, 70-84 yanlış defteri tekrarı yeterli, 70 altı o kazanımın konu anlatımı sınav sabahı bir kez daha okunur. Her soruda **yöntem/kural**, **işlem** ve **sonuç** ayrı puanlanır; yalnızca sonuç yazılmışsa yarım puan.

**SORU 1 (11p)**
- a (4p): 5·10⁹ + 0,2·10⁹ = 5,2·10⁹ (ortak çarpan parantezi; üsler eşit).
- b (4p): 5·10⁹ ÷ 6·10⁶ = (5/6)·10³ ≈ 833 → yaklaşık **833 katı** (ya da 0,83·10³).
- c (3p): a·xⁿ + b·xⁿ = (a + b)·xⁿ ; xᵃ ÷ xᵇ = xᵃ⁻ᵇ (tabanlar aynı, üsler çıkarılır).

**SORU 2 (12p)**
- a (3p): mutfak √20 = 2√5 m; kiler √5 m; salon 2√5 + √5 = 3√5 m.
- b (3p): (3√5)² = 9·5 = **45 m²**.
- c (3p): 20 + 5 + 45 = 70 m² → 70·975 = **68 250 TL**.
- ç (3p): dereceleri 6'da eşitle: √2 = ⁶√(2³) = ⁶√8, ³√3 = ⁶√(3²) = ⁶√9 → ⁶√72.

**SORU 3 (11p)**
- a (6p, 2p her biri): çevre |x − 69| ≤ 1 ; kütle |x − 430| ≤ 20 ; basınç |x − 0,85| ≤ 0,25.
- b (3p): |x − 430| > 20 → (−∞, 410) ∪ (450, ∞) (uygulamada (0, 410) ∪ (450, ∞)).
- c (2p): 68 ve 70'te dolu noktalar, arası taralı; {x | 68 ≤ x ≤ 70, x ∈ R}.

**SORU 4 (11p)**
- a (5p): A ∩ S = [68, 70] (68 ≤ x ≤ 70); A \ S = [67, 68) ∪ (70, 71]; S′ = (−∞, 68) ∪ (70, ∞) (x < 68 veya x > 70).
- b (4p): B ∩ K = [410, 440] (410 dolu, 440 dolu); K \ B = (440, 450] (440 boş, 450 dolu).
- c (2p): Fabrikanın aralıkları standardın **alt kümesi** olmalı: A ⊂ S ve B ⊂ K olacak biçimde çevreyi [68, 70]'e, kütleyi [410, 450] içine daraltmalı; A \ S ve B \ K boş küme olmalı.

**SORU 5 (10p)**
- a (2p): Karşılaştırılabilirlik ve geçişme: 57,32 < 57,38 < 57,67 → Barış.
- b (2p): Değişmezdi; a < b ise a + c < b + c (toplama ile sıralamanın korunması).
- c (3p): Üçü de 57 s olurdu, birinci belirlenemezdi; rasyonel sayılarda **arada olma** özelliği vardır (57 ile 58 arasında sonsuz rasyonel), doğal sayılarda yoktur.
- ç (3p): 3a − 3b = 3(a − b) ∈ C → çıkarmaya **kapalı**; 3 ÷ 6 = 1/2 ∉ C → bölmeye **kapalı değil** (karşıt örnek).

**SORU 6 (11p)**
- a (4p): I. ∀a, b ∈ R, a·b = 0 ⇔ (a = 0 ∨ b = 0). II. ∃x ∈ Q, x² = 2. III. ∀x ∈ Z, x çift ⇒ x² çift.
- b (3p): II **yanlış** (√2 irrasyonel). Değili: ∀x ∈ Q, x² ≠ 2 → "Hiçbir rasyonel sayının karesi 2 değildir" → doğru.
- c (4p): Hipotez: x çift, x = 2k (k ∈ Z). Hüküm: x² çift. İspat: x² = 4k² = 2(2k²) → çift. ∎

**SORU 7 (12p)**
- a (4p): 25,5² − 14,5² = (25,5 − 14,5)(25,5 + 14,5) = 11·40 = **440 m²**.
- b (2p): 440·120 = **52 800 TL**.
- c (3p): Kenarı (a + b) olan kare dört bölgeye ayrılır: a² (kare), ab ve ab (iki dikdörtgen), b² (kare); toplam alan a² + 2ab + b² = (a + b)².
- ç (3p): (x + 1/x)² = x² + 2 + 1/x² → 25 = x² + 1/x² + 2 → **23**. İki terimin toplamının karesi özdeşliği.

**SORU 8 (11p)**
- a (4p): f(x) = x ; g(x) = 2x + 3 ; h(x) = 6. Bağımsız: zaman x (dk); bağımlı: su miktarı (L).
- b (4p): f orijinden eğim 1; g (0, 3)'ten eğim 2 (daha dik); h y = 6 yatay doğru. Üç grafik doğru çizilmiş ve etiketlenmiş.
- c (3p): y-kesme 3 → başlangıçta kaptaki 3 L su; eğim 2 → dakikada 2 L dolum hızı. g daha çabuk dolar: eğimi büyük ve başlangıçta önde (19 L için f: 19 dk, g: 8 dk).

**SORU 9 (11p)**
- a (3p): f sıfırı 0; (−∞, 0) negatif, (0, ∞) pozitif. g sıfırı −3/2; (−∞, −3/2) negatif, (−3/2, ∞) pozitif. Ortak özellikler: tanım ve görüntü R, artan, bire bir, max-min yok.
- b (3p): h(x) = 6: eğim 0; ne artan ne azalan (sabit); bire bir **değil**; max = min = 6; sıfırı yok (6 ≠ 0); işareti her yerde pozitif.
- c (3p): [0, 8]'de artan → min g(0) = 3, max g(8) = 19; görüntü [3, 19]. Kap 19 L'de dolar: 2x + 3 = 19 → **x = 8 dk**.
- ç (2p): k(x) = 2(x + 1) − 3 = **2x − 1**; eğim 2; sıfırı x = 1/2.
