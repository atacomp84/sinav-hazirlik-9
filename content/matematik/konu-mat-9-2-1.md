# Konu Anlatımı — 9.2.1 Doğrusal Fonksiyonlar ve Nitel Özellikleri

Kaynak: MEB 9. Sınıf Matematik Ders Kitabı (1. Kitap) s. 91-116. Senaryo 2'de **1**, Senaryo 3'te **2 soru** (Senaryo 1 ve 4'te yok). Kazanım, f(x) = x **referans fonksiyonu** ve ondan türetilen g(x) = a·f(x ± r) ± k doğrusal fonksiyonlarının **nitel özellikleri**ni kapsar.

**Sınavda ne beklenir:** Gerçek yaşam bağlamı (taksimetre ücreti, depodaki benzin, iki aracın mesafesi, kaba dolan su, koşucuların konumu) ve fonksiyonun cebirsel ya da grafik temsili verilir. Senden: bağımlı-bağımsız değişkeni, tanım ve görüntü kümesini, **sıfırını**, **işaretini**, **artan-azalan** oluşunu, **maksimum-minimumunu**, **bire bir** olup olmadığını, **eğimi** yorumlaman; grafikten fonksiyonu, fonksiyondan grafiği çıkarman beklenir.

---

## 1. Doğrusal ilişki ve referans fonksiyon
İki nicelik arasındaki **doğrusal ilişki** (sabit hızla yürüyen kişinin mesafesi-zaman, fotokopi sayısı-ücret, su sayacı) doğrusal fonksiyonla ifade edilir; grafiği **doğru**dur. **Bağımsız değişken** x (zaman, miktar), **bağımlı değişken** y = f(x) (mesafe, ücret).

**Referans fonksiyon:** f: R → R, **f(x) = x**. Nitel özellikleri (Kontrol Noktası s. 97):

| Nitel özellik | f(x) = x |
|---|---|
| Tanım kümesi | R |
| Görüntü kümesi | R |
| **Sıfırı** (f(x) = 0 yapan x) | x = 0 |
| **İşareti** | x ∈ (−∞, 0) için negatif, x ∈ (0, ∞) için pozitif |
| **Artanlık-azalanlık** | R'de **artan** (x arttıkça f(x) artar) |
| Maksimum / minimum noktası | **yok** |
| **Bire birlik** | bire bir (farklı x'lere farklı f(x)) |
| Eğim | 1 (y = x doğrusu, açıortay) |

### Tanımlar
- **Tanım kümesi:** bağımsız değişkenin alabileceği tüm değerler. **Görüntü kümesi:** karşılık gelen bağımlı değerler.
- **Fonksiyonun sıfırı:** f(x) = 0 eşitliğini sağlayan x (grafiğin x eksenini kestiği nokta).
- **İşaret tablosu:** sıfırın solu ve sağında f(x)'in işareti.
- **Artan:** a < b iken f(a) < f(b). **Azalan:** a < b iken f(a) > f(b).
- **Maksimum/minimum:** tanım aralığındaki en büyük/en küçük değer (R'de tanımlı doğrusal fonksiyonda yoktur; **kapalı aralıkta** uçlarda alınır).
- **Bire bir:** f(a) = f(b) ⇒ a = b (yatay doğru testi).

## 2. g(x) = ax (referansın a ile çarpımı)

| | a > 0 | a < 0 |
|---|---|---|
| Artanlık | **artan** | **azalan** |
| İşaret | (−∞, 0) negatif, (0, ∞) pozitif | (−∞, 0) pozitif, (0, ∞) negatif |
| Sıfırı | 0 | 0 |
| Bire bir | evet | evet |
| Max/min | yok | yok |
| Grafik | |a| > 1 ise f(x) = x'e göre **y eksenine yakın** (dik); |a| < 1 ise **x eksenine yakın** (yatık) | orijinden geçen, sağa doğru inen doğru |

**Eğim = a**: x bir birim artınca y'nin değişimi. h(x) = 3x dik, k(x) = x/2 yatık, m(x) = −2x azalan. Cebirsel ispat: a > 0, c < d → ac < ad → g(c) < g(d) artan; a < 0 → ac > ad azalan.
Kitap: A ve B araçları h(x) = x/2 ve k(x) = 2x, [0, 20] saniyede → h min 0, max 10 m/s; k min 0, max 40 m/s → B daha hızlı hızlanır (eğim büyük).

## 3. g(x) = ax + b (ve genel g(x) = a·f(x ± r) ± k)
g(x) = a·f(x ± r) ± k = a(x ± r) ± k düzenlenince **mx + n** biçimine gelir. Örnek: g(x) = 2·f(x − 3) + 1 = 2x − 5.

| Nitel özellik | g(x) = ax + b (a ≠ 0) |
|---|---|
| Tanım / görüntü | R / R |
| **Sıfırı** | x = −b/a (x eksenini kestiği nokta) |
| **y eksenini kestiği nokta** | (0, b): b **sabit terim**, grafiği yukarı-aşağı **öteler** |
| İşaret | a > 0: (−∞, −b/a) negatif, (−b/a, ∞) pozitif; a < 0 tersi |
| Artan / azalan | a > 0 artan; a < 0 azalan |
| Max / min | R'de yok; [p, q] aralığında uçlarda |
| Bire bir | evet |
| **Eğim** | a (birim değişim oranı) |

Örnekler: h(x) = 2x − 5 → sıfırı 2,5, y-kesme −5, artan. m(x) = −x + 3 → sıfırı 3, azalan, işaret (−∞, 3) pozitif. n(x) = −3x − 4 → sıfırı −4/3, azalan.
**Sıra Sizde:** g(x) = x + 2 ve h(x) = x − 2: eğimleri 1 (f'ye paralel), sıfırları −2 ve 2, y-kesmeleri 2 ve −2, artan, bire bir, max-min yok.

### Gerçek yaşam yorumları (kitabın örnekleri)
- **Taksimetre:** f(x) = 17x + 30, x alınan yol (km). Eğim 17 = km başına ücret; 30 = açılış ücreti (y-kesme). Artan.
- **Benzin:** g(x) = −x/10 + 20, x dakika. Eğim −1/10 = dakikada harcanan benzin; 20 = başlangıç deposu; **azalan**; sıfırı x = 200 dk (benzinin bittiği an); [0, 60]'ta görüntü [14, 20].
- **İki araç:** f(x) = 70x, g(x) = 130x − 260. Eğimler 70 ve 130 → B daha hızlı. g'nin sıfırı x = 2 → B **2 saat sonra** yola çıktı. Kesişim 70x = 130x − 260 → x = 13/3 ≈ 4,33 saat (4 ile 5 arasında yan yana). 6. saatte 420 ve 520 km.
- **Su kapları:** f(x) = x (dakikada 1 L), g(x) = 2x + 2 (başlangıçta 2 L, dakikada 2 L). g'nin y-kesmesi 2 başlangıçtaki suyu, eğim 2 dolum hızını gösterir; g daha çabuk dolar. 19 L kap: f için 19 dk, g için 8,5 dk.
- **Koşucular:** 1. koşucu g(x) = 6x; 2. koşucu h(x) = 7,5x; 3. koşucu k(x) = 5x + 2 (başlangıçta 2 m önde); 4. koşucu m(x) = 2,5x + 3; hakem n(x) = 6 (**sabit fonksiyon**, hareketsiz). Eğim = hız, sabit terim = başlangıç konumu.

## 4. Sabit fonksiyon g(x) = k
a = 0 durumu: g(x) = k. Grafik **x eksenine paralel** doğru, eğim **0**. Her x için aynı değer → **bire bir değil**, artan da azalan da değil (sabit), maksimum = minimum = k, k ≠ 0 ise **sıfırı yok**, işareti k'nin işareti. Sabit fonksiyon da doğrusal fonksiyondur.

## 5. Aralıkta tanımlı fonksiyon ve parçalı gösterim
- f(x) = x fonksiyonu [1, 5]'te tanımlanırsa min 1, max 5 (uçlarda). (1, 5)'te tanımlanırsa **max/min yoktur** (uçlar dâhil değil).
- Farklı aralıklarda farklı kurallar: **parçalı fonksiyon**. Buzun ısınması: f(t) = 4(t − 5), 0 ≤ t < 5 (buz ısınıyor); f(t) = 0, 5 ≤ t < 10 (erime); … Genel ağ ücreti: ilk 100 GB 200 TL (sabit), sonrası 200 + 0,5(x − 100).

## 6. Grafik okuma ve çizme adımları
1. Eğim pozitifse sağa yukarı, negatifse sağa aşağı; |a| büyüdükçe dikleşir.
2. y eksenini kestiği nokta (0, b); x eksenini kestiği nokta (−b/a, 0).
3. İki noktayı birleştir. Eğim = (y₂ − y₁)/(x₂ − x₁).
4. Grafikten fonksiyon yazarken y-kesme b, eğim a bulunur: g(x) = ax + b.
5. Aralıkta tanımlıysa uç değerleri işaretle; max-min oradadır.

## 7. Sık yapılan hatalar
- Sıfırı ile y-kesmeyi karıştırmak: sıfır x = −b/a (x ekseni), y-kesme b.
- a < 0 iken işaret tablosunu a > 0 gibi yazmak.
- Sabit fonksiyonu bire bir sanmak ya da "azalan" demek.
- R'de tanımlı doğrusal fonksiyona max/min yazmak.
- Eğimi yorumlamamak: sınav "eğim ne anlama gelir" der → **birim başına değişim** (hız, km başına ücret, dakikada litre).
- Açık aralıkta uç değeri max/min saymak.
