# Konu Anlatımı — 9.1.1 Gerçek Sayıların Üslü ve Köklü Gösterimleri ile İşlemler

Kaynak: MEB 9. Sınıf Matematik Ders Kitabı (1. Kitap) s. 13-36. **Her senaryoda 2-3 soru**; sınavın en ağır konusu.

**Sınavda ne beklenir:** Gerçek yaşam bağlamlı sorular: gök cisimlerinin kütleleri (bilimsel gösterim), nüfus yoğunluğu, kare bahçenin kenarı ve çiti (köklü sayı, yaklaşık değer), serbest düşme süresi, basamak sayısı bulma. Senden hem **işlemi doğru yapman** hem de **"önerme"** biçiminde kuralı yazıp **gerekçelendirmen** beklenir (kazanım: "işlemlere dair **muhakeme** yapabilme"). Cevapta kural + işlem + sonuç + birim.

---

## 1. Üslü gösterim

**Tanım:** a gerçek sayı, n pozitif tam sayı olmak üzere n tane a'nın çarpımı **aⁿ** (a: taban, n: üs). Örnek: 2⁵ = 32, (−2)⁵ = −32, (−1)⁶ = 1, −3⁴ = −81 (eksi üssün dışında!).

| Kural | Örnek |
|---|---|
| a⁰ = 1 (a ≠ 0); 0ⁿ = 0 (n > 0); 0⁰ tanımsız | 8⁰ = 1, (−6)⁰ = 1, 0⁵ = 0 |
| a⁻ⁿ = 1/aⁿ ; a⁻¹ = 1/a | 4⁻¹ = 1/4, 3⁻² = 1/9, (−5)⁻³ = −1/125, (2/3)⁻² = 9/4 |
| Negatif tabanda çift üs pozitif, tek üs negatif | (−3)⁴ = 81, (−3)³ = −27 |

### Toplama ve çıkarma (ortak çarpan parantezi)
Tabanı **ve** üssü aynı olan üslü ifadeler toplanıp çıkarılır: **a·xⁿ + b·xⁿ = (a + b)·xⁿ**.
- 3·5¹⁰ + 5¹⁰ = 4·5¹⁰ ; 5·7¹² − 2·7¹² = 3·7¹² ; 0,4·5⁷ + 2,1·5⁷ = 2,5·5⁷
- 3·10⁵ − 10⁵ + 2,5·10⁵ = 4,5·10⁵
- **Üsler farklıysa önce eşitle:** 7,5·10⁸ − 5,8·10⁷ = 75·10⁷ − 5,8·10⁷ = 69,2·10⁷ = 6,92·10⁸ km (Merkür-Jüpiter uzaklığı).

### Çarpma ve bölme
| Kural | Örnek |
|---|---|
| Tabanlar aynı: xᵃ · xᵇ = xᵃ⁺ᵇ ; xᵃ ÷ xᵇ = xᵃ⁻ᵇ | 2³·2⁴ = 2⁷ ; 3⁶·3⁻⁴ = 3² ; 5⁻⁴·5⁷ = 5³ ; (−6)²·(−6)³·(−6) = (−6)⁶ |
| Üsler aynı: xᵃ · yᵃ = (x·y)ᵃ ; xᵃ ÷ yᵃ = (x/y)ᵃ | 2³·5³ = 10³ ; 3⁴·4⁴ = 12⁴ ; (−2)⁵·(−7)⁵ = 14⁵ |
| Üssün üssü: (xᵃ)ᵇ = xᵃ·ᵇ | (3²)³ = 3⁶ ; (5⁴)⁶ = 5²⁴ ; (−2⁵)² = 2¹⁰ ; 1 GB = 2¹⁰ MB = (2¹⁰)³ B = 2³⁰ B |

Örnek: A = 3·2¹¹, B = 7·5¹¹ → A·B = 21·10¹¹ → **13 basamaklı** (21'in yanına 11 sıfır).

### Bilimsel gösterim
**a·10ⁿ**, 1 ≤ |a| < 10, n tam sayı. 1 080 000 000 = 1,08·10⁹ ; 0,00000000000000175 = 1,75·10⁻¹⁵. Karşılaştırmada üsleri eşitleyip katsayıları karşılaştır: 1,09·10⁶ m, 123·10⁴ m = 1,23·10⁶ m, 10,54·10⁵ m = 1,054·10⁶ m → sıralama 1,054 < 1,09 < 1,23.

Kitap örneği: 66,22 kg'lık insanda atom sayısı 66,22·10²⁶ = 6,622·10²⁷; 1 mol = 6,02·10²³ atom → 6,622·10²⁷ ÷ 6,02·10²³ = 1,1·10⁴ mol.

### Basamak sayısı bulma
Sayıyı **10'un kuvveti** cinsinden yaz: 2'ler ve 5'leri eşle. Örnek: A = 2¹⁶·5¹⁴·3 = 2²·3·(2·5)¹⁴ = 12·10¹⁴ → 12'nin yanında 14 sıfır → **16 basamaklı**. Genel: k·10ⁿ sayısı, k'nin basamak sayısı + n basamaklıdır.

## 2. Köklü gösterim

**Tanım:** m, n pozitif tam sayı, n ≥ 2, x > 0 için **x^(m/n) = ⁿ√(xᵐ)**; n: kökün derecesi. ²√ yerine √ yazılır. 49^(1/2) = √49 = 7; 8^(2/3) = ³√64 = 4; 5^(3/2) = √125.

| Kural | Açıklama / örnek |
|---|---|
| Çift dereceli kökün içi ≥ 0 olmalı; sonuç ≥ 0 | √(−4) gerçek sayı değil; ⁴√16 = 2 |
| Tek dereceli kök her gerçek sayı için tanımlı | ³√(−8) = −2 |
| ⁿ√(aⁿ) = a (n tek), = |a| (n çift) | √((−3)²) = 3 |
| Kök dışına çıkarma: ⁿ√(aⁿ·b) = a·ⁿ√b | √75 = 5√3 ; √48 = 4√3 ; √108 = 6√3 ; ³√24 = 2·³√3 |

### Toplama-çıkarma
Yalnızca **derecesi ve kök içi aynı** olanlar: a·ⁿ√x + b·ⁿ√x = (a+b)·ⁿ√x. Önce sadeleştir.
- √75 − 2√12 + 5√27 = 5√3 − 4√3 + 15√3 = **16√3**
- √108 − √48 = 6√3 − 4√3 = 2√3 sn (iki cismin düşme süreleri farkı)
- √0,09 − √1,21 + √0,04 + √0,36 = 0,3 − 1,1 + 0,2 + 0,6 = 0

### Çarpma-bölme
Dereceler aynıysa kök içleri çarpılır/bölünür: ⁿ√x · ⁿ√y = ⁿ√(xy), ⁿ√x ÷ ⁿ√y = ⁿ√(x/y).
- √20 · √5 = √100 = 10 ; ³√24 · ³√9 = ³√216 = 6 ; √54 ÷ √6 = √9 = 3
- **Dereceler farklıysa eşitle** (derecelerin OKEK'i, kök içini aynı sayıyla kuvvetlendir): √2 · ³√5 = ⁶√(2³) · ⁶√(5²) = ⁶√(8·25) = **⁶√200**.
- Derece genişletme-sadeleştirme: √3 = ⁶√27 (3 ile genişletme); ⁶√(5⁴) = ³√(5²) (2 ile sadeleştirme); ¹²√(3¹⁶) = ³√(3⁴) (4 ile sadeleştirme).

### Kökün kökü
ᵐ√(ⁿ√x) = ᵐ·ⁿ√x : √(³√64) = ⁶√64 = 2.

### Sıralama
Dereceleri eşitle, kök içlerini karşılaştır: a = √2, b = ³√3, c = ⁶√5 → ⁶√8, ⁶√9, ⁶√5 → **c < a < b**. (Kitap örneği: dereceler 18'de eşitlenir.)

### Eşlenik ve paydayı rasyonel yapma
- 1/√a = √a/a (pay ve payda √a ile çarpılır): 1/√5 = √5/5.
- (√a − √b)(√a + √b) = a − b → **eşlenik**. 1/(√5 − √3) = (√5 + √3)/(5 − 3) = (√5 + √3)/2.
- 1/(2 + √3) = (2 − √3)/(4 − 3) = 2 − √3. Toplama örneği: 1/(2+√3) + 1/(2−√3) = (2−√3) + (2+√3) = 4.

### Yaklaşık değer (kitabın yöntemi, s. 34-35)
√3: 1² = 1 < 3 < 4 = 2² → 1 ile 2 arası, 4'e yakın → 1,5² = 2,25 < 3 → 1,5 ile 2 arası; 1,75² = 3,0625 > 3 → 1,5 ile 1,75 arası, 3,0625'e yakın → **√3 ≈ 1,75** (gerçek 1,732).
**Çit problemi:** 1200 m² kare arazi → kenar √1200 = 20√3 ≈ 20·1,75 = 35 m → çevre 140 m → 140 ÷ 5 = 28 panel → 28·1700 = **47 600 TL**.

### Gerçek yaşamda kök
- Düşme süresi t = √(2h/g). h = 11,5 m, g = 9,8 → t = √(23/9,8) ≈ 1,53 s. 0,5 m'den düşme + sonra 2 m'den düşme toplam süre: √(1/9,8) + √(4/9,8) ≈ 0,32 + 0,64 = 0,96 s.
- Kare mutfak 20 m², kare kiler 5 m², kenarlar √20 = 2√5 ve √5; salon kenarı 3√5 → alan 45 m²; toplam alan 20 + 5 + 45 = 70 m² → 70·975 = **68 250 TL** parke.
- Ay'da zıplayan cisim: a m yükseklikten bırakılırsa 1. çarpma sonrası √a, 2. sonrası ⁴√a, 3. sonrası ⁸√a m yükselir.

## 3. Önerme yazma kalıbı (sınavda puan)
Kitap kuralı "önerme" olarak ister: *"x sıfırdan farklı bir gerçek sayı, a ve b tam sayı olmak üzere xᵃ·xᵇ = xᵃ⁺ᵇ'dir."* Gerekçe: açık yazılınca a tane x ile b tane x çarpılır, toplam a + b tane x. **Doğrulama:** 2³·2⁴ = (2·2·2)(2·2·2·2) = 2⁷. Sınavda kuralı yaz → gerekçele → sayısal doğrula → problemde kullan.

## 4. Sık yapılan hatalar
- −3⁴ ile (−3)⁴'ü karıştırmak (−81 ve 81).
- Tabanlar farklı, üsler farklıyken çarpmaya kalkmak; 2³·3² sadeleşmez (72).
- 2³ + 2⁴ = 2⁷ yazmak (doğrusu 8 + 16 = 24 = 3·2³).
- √a + √b = √(a+b) yazmak (√9 + √16 = 7 ≠ √25 = 5).
- Dereceleri farklı kökleri doğrudan çarpmak.
- Bilimsel gösterimde katsayıyı 1-10 aralığında bırakmamak (69,2·10⁷ yerine 6,92·10⁸).
- Çift dereceli kökten negatif sonuç çıkarmak (√16 = ±4 **değil**, 4).
