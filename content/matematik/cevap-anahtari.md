**C3.**

## BÖLÜM D — 9.1.4

**D1.** Özellikler (7p): ∀a, b, c ∈ R: a + b = b + a, a·b = b·a (değişme); (a+b)+c = a+(b+c), (ab)c = a(bc) (birleşme); a + 0 = a, a·1 = a (birim); a + (−a) = 0, a·(1/a) = 1 (a ≠ 0) (ters); a·0 = 0 (yutan, yalnız çarpmada); a(b + c) = ab + ac (dağılma). Çıkarma-bölme (3p): değişme, birleşme, birim ve ters eleman yok: 5 − 3 ≠ 3 − 5; (8 ÷ 4) ÷ 2 ≠ 8 ÷ (4 ÷ 2).

**D2.**
- a (3p): ∀a, b, c ∈ R, (b > a ∧ c > b) ⇒ a < c.
- b (4p): "Her gerçek sayının karesi sıfıra eşit veya sıfırdan büyüktür" (doğru). Değili: ∃x ∈ R, x² < 0 ("bazı gerçek sayıların karesi negatiftir") → **yanlış**.
- c (3p): ∀a ∈ R, a ≠ 0 için ∃b ∈ R öyle ki a·b = 1 → çarpma işleminde **ters eleman** özelliği (b = 1/a).

**D3.**
- a (4p): 15,75² − 14,25² = (15,75 − 14,25)(15,75 + 14,25) = 1,5·30 = **45 m²**; 15,75² − 11,25² = 4,5·27 = **121,5 m²**.
